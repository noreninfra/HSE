# HSE — домашнее задание по Git

Учебный проект на Python для отработки работы с Git и GitHub.

## Описание программы

В файле `employee.py` реализован класс `Employee`, который позволяет:

- создавать сотрудника с именем и зарплатой;
- повышать зарплату на указанную сумму;
- выводить данные сотрудника на экран.

## Запуск

```bash
python employee.py
```

Пример результата:

```text
Сотрудник Иван, зарплата 1300
```
